# TanStack Start test app of the Flags SDK

Tests the Flags SDK with TanStack Start: the framework binding of
`flags()` (the request with `getRequest()`,
and `flags.config.ts`), the registration of `'use flags'` modules, the
manifest of the flags, and `redirect()` through the SDK. Flags run in
server functions and server routes.

```sh
pnpm test:e2e
```
